# Маникюр в Кимрах — Анастасия Морозова

Одностраничный сайт мастера маникюра. Статика, публикуется через GitHub Pages из ветки `main`.

- `index.html` — страница (тексты, контакты, цены, SEO-теги и разметка schema.org в `<head>`)
- `photos/` — фотографии
- `vendor/`, `support.js` — рантайм анимаций

Локально: `python3 -m http.server` в этой папке и открыть http://localhost:8000.

При подключении своего домена заменить адрес `https://pulivilizator-projects.github.io/manic-gold/` в `index.html`, `robots.txt` и `sitemap.xml`.
